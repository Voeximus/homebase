## The one job
Logging a real set takes one tap, and what you logged is honest afterwards.

## Ships

1. **Logger** (the most important screen)
   - Each exercise card: name (tap → exercise page) and one faint line "Last time (Tue 3 Sep): 185×5 · 185×5 · 185×4" from the person's most recent *finished* session containing that exercise.
   - Set rows: weight and reps inputs. Empty inputs show last time's value for the same set position faintly (warm-ups matched to warm-ups, working to working); if none, the previous row in this session.
   - One big tick per row (48×48). Tapping it fills empty inputs from the faint values and marks the set done (`done: true`, `doneAt`, `id`). A weighted exercise with no weight anywhere refuses: the weight box shakes, "Enter a weight", nothing saved. Tapping a done tick un-ticks.
   - Set number cell toggles **W** (warm-up) ↔ number.
   - Add set, remove set, add exercise (existing search sheet), remove exercise.
   - **Rest dock** above the tab bar: starts when a set is ticked. Big countdown, −15, +15, Skip. Stored as an end time, so it survives the screen sleeping or the app reloading. At zero: a short Web Audio beep, `navigator.vibrate` where it exists, dock says "Rest over". Defaults: warm-up 60 s; bodyweight/band/timed 60 s; compound 120 s; isolation 90 s; cardio no timer.
   - Screen Wake Lock held while a session is open (re-requested when the page becomes visible again).
   - **Finish:** sets with no numbers are dropped; if nothing was ticked: "Nothing was logged. Discard this workout?". **Discard** asks to confirm.
   - Session time: start time kept on the phone; shown as elapsed in the session bar.
2. **Exercise page**: body map (main = solid, helps = striped; front and back figures ported from the mockup), the line "Main: … · Helps: …", then **What studies found** — every kept claim attached to this exercise, `correctedClaim` word for word, grade badge (■ Tested over weeks / ◧ Measured in one workout / □ Reasoned, not tested), "Tested on a similar exercise, not this one." for `variation`, sources collapsed. No claims → exactly: "No study notes for this exercise yet. The muscles shown come from anatomy, not from a study of this exercise." Then **Your numbers**: heaviest weight for at least 1/3/5/8/10/12 reps, and the last 3 sessions.
3. **Exercises tab**: search + body-area chips (All · Chest · Back · Shoulders · Arms · Core · Legs · Cardio) → exercise page.
4. **Progress tab**: hard sets per muscle region, last 7 days (ticked working sets; main muscle = 1, helper = 0.5; warm-ups never count), each with a bar, tick marks at 4, 10 and 18, and the band label; a line "Sets with no muscle detail: N". Then recent records with dates.
5. **Navigation inside Workouts**: Today · Progress · Exercises · Together. Today and Together keep their current content, except: the "vol" number is removed everywhere (it adds pounds×reps to bare reps), and an unfinished session from an earlier day shows a banner "Unfinished workout from Tue 9 Sep · Finish it · Discard" instead of pretending to be today's workout.
6. **Library data**: every one of the 186 existing exercises (ids and names unchanged) gets `primary`/`secondary` regions and `mode`; add Homebase-authored "Band row", "Nordic hamstring curl", "45° back extension"; add aliases for names old routines use ("Incline dumbbell press", "Chest-supported row", "Flat dumbbell press", "Dumbbell hammer curl", "Dumbbell split squat", "Walk"); fix Romanian deadlift → legs, Face pull → shoulders.
7. **Evidence**: `src/lib/evidence.ts` generated from `docs/research/workout-mode/evidence.json` — kept claims only, attached to library exercises by `showOn`; dropped ids appear nowhere in `src/`.
8. **Maths**: warm-ups excluded from records and hard sets; e1RM: 1 rep → the weight itself, none above 15 reps; records keyed by normalised exercise name (+ aliases).
9. **Never lose a set**: dirty flag cleared only if no newer edit happened since the save started; merge set by set when sets have ids; repair duplicate set ids on load; a crash-safe copy of the running session on the phone, merged back on load.
10. **Chinese** for every new string and every region name. Exercise names stay as they are today.
11. **`?workoutlab`** dev page with a fake store — the only place UI is checked. Never Supabase.

Bands (hard sets in 7 days → label): 0 "None" · under 4 "Below the lowest band in the studies" · 4 "Minimum band" · over 4 to 10 "Most growth for each set" · over 10 to 18 "More in total, less for each extra set" · over 18 to 29 "Less for each extra set" · 30 to 42 "Least for each extra set" · 43+ "Not enough studies to say".
